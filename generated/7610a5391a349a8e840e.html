学习笔记使用说明

这里是私有 Obsidian 笔记库。笔记使用 Markdown 格式。

  1. 在 Notes 文件夹写学习笔记，插入“学习笔记”模板。
  2. 笔记顶部的 publish 是复选框，默认不勾选。
  3. 只有你阅读并确认适合公开后，才手动勾选 publish。
  4. 运行仓库根目录的“同步笔记.cmd”，把本地改动推到私有仓库。
  5. GitHub Actions 配置完成后，会检查并发布已勾选的 Notes 笔记。

没有 publish 属性的笔记不会公开。模板、Zotero 原始导入、附件和应用配置不参与公开。

取消勾选后，下次发布会从公有仓库当前版本和网站移除。Git 历史和他人的副本不一定消失。

发布检查能阻止一些常见敏感内容，但不能替代人工审核。链接到未公开笔记、附件、原始 HTML 等会被保守拒绝。

Zotero 文献保存到 Sources/Zotero。先运行“导入文献.cmd”，再在 Notes 中撰写自己的阅读笔记。
